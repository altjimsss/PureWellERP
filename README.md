# PureWell ERP

ERP-style web app with a JavaFX desktop wrapper.  
Modules: HRM, Finance & Accounting, Procurement & Inventory, Sales & Delivery.

## Quick Start
```bash
cd demo
mvn spring-boot:run
```
Open `http://localhost:8080/login`.

## Desktop App
```bash
cd demo
mvn javafx:run
```
